# زمان‌یار — نسخه ۱.۵ (سورس برای ساخت APK)

جزئیات تغییرات و راهنمای نسخه جدید: [README-v1.5-FA.md](README-v1.5-FA.md)

برنامه بومی اندروید (Java)، کاملاً آفلاین، با پایگاه داده SQLite و رابط فارسی راست‌به‌چپ.

## ساخت در Android Studio
1. فایل ZIP را استخراج کنید؛ پوشه `Zamanyar-Final` را با گزینه **Open** باز کنید.
2. Android Studio با JDK 17 و Android SDK Platform 35 نیاز است. هنگام اولین Sync به اینترنت برای دریافت Android Gradle Plugin 8.7.3 نیاز دارید.
3. منتظر پایان **Gradle Sync** بمانید.
4. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** استفاده کنید.
5. مسیر خروجی: `app/build/outputs/apk/debug/app-debug.apk`.
6. فایل APK را به گوشی منتقل کنید و نصب کنید. در صورت درخواست سیستم، مجوز نصب از این منبع را فعال کنید.

## قابلیت‌های موجود در سورس
- ثبت/ویرایش/حذف جلسات، وظایف، رویدادها و نمایش جزئیات
- داشبورد آمار و پیشرفت، برنامه‌های امروز، جست‌وجوی ساده
- تقویم شمسی ماهانه و نمایش هفتگی؛ تاریخ‌گزین شمسی با چرخ انتخاب
- تکرار روزانه، هفتگی، ماهانه و سالانه؛ تبدیل مصوبه جلسه به وظیفه
- گزارش آماری، یادآوری محلی، بازیابی اعلان پس از راه‌اندازی مجدد
- پشتیبان‌گیری و بازیابی JSON از طریق انتخاب فایل اندروید

## محدودیت‌ها و نکات ضروری
- این نسخه **کامپایل یا روی دستگاه تست نشده** و نباید به‌عنوان APK تست‌شده معرفی شود.
- رابط کاربری هنوز کاملاً مشابه طرح تصویری مفهومی نیست.
- تکرارها در تقویم مجازی‌اند و گزارش آن‌ها را جداگانه نمی‌شمارد.
- برای اطلاع‌رسانی مطمئن، محدودیت‌های باتری و مجوز اعلان اندروید باید بررسی شوند.
- برنامه به اینترنت نیاز ندارد؛ دریافت ابزارهای ساخت ممکن است نیازمند اینترنت باشد.
- از اطلاعات خود مرتباً فایل پشتیبان JSON تهیه کنید؛ حذف برنامه ممکن است داده‌های محلی را پاک کند.
- بعد از ساخت، ثبت و ویرایش تاریخ شمسی، اعلان‌ها، بکاپ و بازیابی را روی گوشی تست کنید.
